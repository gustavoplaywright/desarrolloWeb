# Tech Soluciones

Sitio web estático de Tech Soluciones, creado con HTML, Sass, Bootstrap y Animate.css.

## Requisitos

- Node.js y npm

## Desarrollo

Instala las dependencias:

```bash
npm install
```

Compila Sass una vez:

```bash
npm run build:css
```

Para recompilar automáticamente mientras editas los archivos Sass:

```bash
npm run sass
```

Abre `index.html` en un navegador o sirve la carpeta raíz con un servidor estático. Las páginas adicionales están en `pages/`, los estilos fuente en `scss/` y los estilos compilados en `styles/style.css`.
